DEPLOYMENT FROM MACBOOK:

Step 1: Copy files to MacBook
───────────────────────────
scp -r arca-oci-workhorse:/home/ubuntu/ARCA/services/user_interaction_agent ~/ARCA/services/

Step 2: Build Docker image
───────────────────────────
cd ~/ARCA/services/user_interaction_agent
./build_and_deploy.sh

Step 3: Deploy to GCP
───────────────────────────
# Option A: Direct docker run
docker run -d --name user_interaction_agent -p 8084:8084 \
  -e AGENT_SERVICE_URL=http://141.147.85.137:8000 \
  -v /var/run/docker.sock:/var/run/docker.sock:ro \
  --restart unless-stopped arca-user_interaction_agent:v3.0.0

# Option B: Using docker-compose
docker-compose -f docker-compose.production.yml up -d

TROUBLESHOOTING:

If you see "Agent service is currently unavailable":

1. Check environment variable:
   docker exec user_interaction_agent env | grep AGENT_SERVICE_URL
   Should show: AGENT_SERVICE_URL=http://141.147.85.137:8000

2. Test GCP → OCI connectivity:
   curl -v http://141.147.85.137:8000/docs

3. If connection fails, check OCI security:
   - OCI Security List: Allow TCP 8000 from 0.0.0.0/0
   - OCI Firewall: sudo iptables -L | grep 8000
   - Agent service running: docker ps | grep agent_service

4. Verify from OCI side:
   curl http://localhost:8000/docs
   Should return HTML (agent service docs)
